# Concept Crack - Product Requirements Document

## Overview
Concept Crack is a comprehensive AI-powered personalized learning and assessment platform. It features four distinct portals (Student, Parent, Faculty, Admin) and focuses on adaptive learning through AI analytics.

## Core Modules & Screens

### 1. Authentication & Public
- **Landing Page**: Hero (AI showcase), Features, Testimonials, Stats, CTA.
- **Login Page**: Role selection (Student, Parent, Faculty, Admin) with multi-method login (Email, Mobile, OTP).

### 2. Student Portal
- **Dashboard**: Performance Score, Rank, Accuracy, Mastery Heatmap, Weekly Trends.
- **Practice Module**: Topic/Subject/Chapter-wise practice, PYQ filters, AI Recommended Practice.
- **Examination Module**: Test listings (Mock, Subject, Full-length), Exam Interface (Timer, Palette, Flagging).
- **Test Analysis**: Score summary, Topic/Difficulty analysis, AI Insights (Strengths/Weaknesses).
- **AI Adaptive Insights**: Learning speed, Consistency, Retention, Knowledge Gap Heatmap.

### 3. Parent Portal
- **Child Overview**: Rank, Attendance, Practice Frequency, Improvement %.
- **Progress Tracking**: Weekly/Monthly growth charts, Concept mastery status.

### 4. Faculty Portal
- **Dashboard**: Student/Test stats, Question bank size, Avg performance.
- **Question Bank Management**: Add Question (MCQ, Numerical, etc.), Repository with search/filters.
- **Student Analytics**: Individual & Batch dashboards, Intervention highlighting at-risk students.

### 5. Admin Portal
- **Global Dashboard**: Revenue, Activity, Institution/User totals.
- **User/Institute Management**: CRUD for users, coaching centers, branches, and batches.
- **Platform Configuration**: AI parameter tuning, RBAC (Permission matrix), Branding.

## Design Goals
- Desktop-first responsive design.
- Minimalist clutter, high-density data visualization.
- Consistent navigation patterns across all portals.
