# Concept Crack

Concept Crack is an AI-powered learning and assessment platform built for students, parents, faculty, and administrators. It combines adaptive practice, exam simulation, performance analytics, and role-based dashboards to help learners study smarter and institutions track progress more effectively.

## What it does

- Personalized study plans and adaptive learning insights
- Student practice, mock tests, and exam analysis
- Parent progress tracking and growth visibility
- Faculty question bank and batch-level analytics
- Admin controls for users, institutes, and platform configuration

## Key Highlights

- Multi-role portal experience for Student, Parent, Faculty, and Admin
- AI-driven recommendations and retention insights
- Data-rich dashboards with charts, heatmaps, and rankings
- Modern responsive UI built with React, Vite, and Tailwind CSS

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express

## Getting Started

```bash
npm install
npm run dev
```
